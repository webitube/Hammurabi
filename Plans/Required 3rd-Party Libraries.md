# Required 3rd-Party Libraries

The following external libraries and tools are required for the implementation of the Hammurabi TypeScript/HTML port.

## Development Tooling
- **Vite**: Build tool and development server.
- **TypeScript 5**: Language for type safety.
- **Vitest**: Testing framework for unit and integration tests.
- **ESLint & Prettier**: Code quality and formatting.

## Core Libraries
- **ReactiveTypescript**: (Internal Project Library) Provides `ReactiveStoreBase`, `ReactiveValue`, `ReactiveList`, etc.

## Assets & Fonts
- **Google Fonts**: Noto Sans Cuneiform (or similar) for the ancient Mesopotamian aesthetic.

## Installation Summary
```bash
# Initialize project and install dependencies
npm install
npm install -D vite typescript vitest eslint prettier
```
